   بـminimal pairs. **بيانات جديدة لا تُسمّى holdout إن استُخدمت في التطوير.**
3. **الحالات الأربع الفاشلة**: `SIN-004`, `FSIN-004`, `FNUM-004`, `FMIX-004`.
4. **`parser_fast_decomposition_enabled`** — وصف مضلل، قرار منتج.

   انظر `review-notes.md`، الافتراض 2.
