# SmartSpend v2.1.0 Classification Core — 5 September 2026

## What this release contains

- A financial-event admission layer before classification: distinct events retain their order and amount ownership; negated, future, question, and incomplete cases are kept out of automatic expense creation.
- Safer number, correction, total, confidence, contract, and post-classification checks for Egyptian Arabic text.
- Reviewed A2 resilience changes: model-compatible provider routes, end-to-end response deadlines, route-scoped circuit breaking, versioned event-scoped classification caching, and a shared pre-STT voice quota gate.
- Administration hardening: sensitive monitoring and account procedures require an administrator; user listings and session inspection project only necessary non-secret fields.

## Validation

- TypeScript check, production build, lint, canonical database tests, Redis tests, classification/A2 acceptance tests, and the administrator security suite all passed in the release validation environment.
- The classification benchmark over 172 synthetic fixtures measured record triple F1 of 88.85% (from 87.31% in the preserved baseline) and unsafe automatic saves of 4 (from 6).
- The broader Vitest run completed with 1652 passing tests and 17 failures in nine non-classification test files (UI stress/assertion setup, static compression, Redis fallback setup, and an action-runtime transaction mock). These are documented release follow-up work and are not represented as a full-suite pass.

## Known limits

This is not a claim of 100% classification accuracy. Currency/date persistence, user-correction learning, full idempotency across every ingestion path, and server-side verification of the real media duration remain separate work. The voice quota gate rejects missing or invalid claimed duration but does not yet derive it from the audio container.
