# mobile/ — the Flutter app

Why it exists and what is decided: `docs/decisions/0022-flutter-mobile-app.md`. Layout, setup and commands:
`mobile/README.md`. Every rule names the check that enforces it (`unenforced` means nothing does yet).

## Rules
1. Call the API only through `TrpcClient` with a constant from `Procedures`; never build an `/api/trpc` address or
   a procedure name by hand. A procedure the server no longer has must stop the build. The one route outside tRPC,
   `/api/sse/otp`, goes through `PhoneChallengeEvents`. (the Dart compiler, once the catalog is regenerated; building
   URLs by hand is unenforced)
2. `packages/smartspend_api/lib/src/generated/procedures.g.dart` is generated by `npm run atlas` from
   `api/router.ts`; never edit or hand-merge it. Staff procedures (`adminProcedure`, `moderatorProcedure`) are left
   out on purpose: the app is for users. (`npm run atlas:check`, `npm run agent:finish`, CI)
3. Server changes for mobile go into the procedures and routes both clients use; there is no mobile-only API. A
   breaking change to a procedure keeps working for the store builds still in users' hands. (unenforced)
4. Code only one platform can run lives in a plugin package in Kotlin or Swift, behind a Pigeon contract in its
   `pigeons/` folder. The Dart side asks the plugin what the phone can do and shows only that. (unenforced)
5. Pigeon and gen-l10n output is committed exactly as the tools write it. (the "Generated code matches its sources"
   step of `.github/workflows/mobile.yml`)
6. Every text a user reads is in `app/lib/src/l10n/app_ar.arb` first, then `app_en.arb`, written as
   `docs/guides/writing-app-messages.md` says. (missing English keys: gen-l10n; text written in Dart code: unenforced)
7. The session token lives only in `SessionStore` (Keychain or Keystore), and `SessionController` is the only code
   that writes or clears it. Never log it, a Google ID token, a message's text, a phone number or a transcript (golden
   rule 10 in the root `AGENTS.md`). (unenforced)
8. The server owns money and time: ledger days and months are Cairo business time computed by the API (golden
   rule 6); the app shows them and never recomputes them from the phone's clock. (unenforced)
9. Nothing secret goes into a dart-define, a config file or this folder: dart-defines ship inside the app, and
   the repository is public. (unenforced)
10. Formatting, analysis and the tests of every package pass. (`.github/workflows/mobile.yml`)
11. Every tab is behind the route guard (`sessionRedirect` in `app/lib/src/routing/app_router.dart`); a new screen
    that needs no session goes under `/sign-in`. (`app/test/route_guard_test.dart`)
